# Free Fire Tournament Platform
# About the Project:
I am developing a website for hosting and participating in Free Fire Tournaments. People who wants to host the tournaments and players who want to join in the tournaments of Free fire are the main target audience of this website.
# Planned Features:
- Signup page
- Filter Tournament based on when it is being held, who is organizing it, and modes.
- Different permission access based on administrator and players.
- Payment method setup
- Basic Tournament information displayed before going into further detail.
